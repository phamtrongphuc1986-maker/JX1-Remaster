2. API integration/smoke tests với database test riêng.
3. Kiểm tra quyền sở hữu nhân vật, xác thực, chống lặp phần thưởng và transaction.
4. Client TypeScript compile trong Cocos Creator 3.8.x.
5. Android ARM64 build, cài đặt và kiểm thử trên OPPO Reno 13F 5G.
6. Kiểm thử nhiều người chơi, reconnect, đồng bộ vị trí và combat server-authoritative.

Không phát hành APK khi còn test blocker nghiêm trọng.
