# Android build

Mục tiêu: APK/AAB Android 64-bit, package `com.cuongchien.online`, tên hiển thị `Cuong Chien Online`.

Chưa có build artifact được xác minh. Cần project Cocos Creator hoàn chỉnh, Android SDK/NDK/JDK tương thích, cấu hình signing an toàn và kiểm thử cài đặt trên thiết bị thật. Không commit keystore hoặc mật khẩu ký.
