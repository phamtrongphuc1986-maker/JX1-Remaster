- Máy chủ authoritative; client không tự quyết định sát thương, HP, EXP, vật phẩm hoặc vị trí.
- Chỉ phát hành khi build và kiểm thử thực tế đạt.
- Không dùng dịch vụ trả phí nếu chưa được chủ dự án đồng ý.

- Đã tạo gói import sạch `JX1M-Clean-Source-Import.tar.gz`, SHA-256 được ghi trong `docs/CODEX_HANDOFF_VI.md`. Gói sạch loại bỏ database sidecars, log và binary.
- Đã thêm `docs/SOURCE_AUDIT_2026-11-28_VI.md` và `docs/CODEX_HANDOFF_VI.md`.
- GitHub Actions đã được nâng cấp: khi có `server/go.mod`, workflow sẽ cài Go theo module, chạy tests, vet, build và API smoke test.
- Workflow mới nhất đã PASS phần kiểm tra tài liệu; bước Go được bỏ qua có chủ đích vì source chưa được nhập vào repository.

## Những việc CHƯA hoàn thành — không được coi là đã có game
- Mã nguồn Go trong gói import sạch chưa được nhập thành các file trong repository.
- Mã nguồn Phase A chưa được ghép/kiểm tra thành một Cocos Creator project hoàn chỉnh.
- Chưa có cấu hình endpoint production, database staging, secrets và deploy lên VPS.
- Chưa build APK/AAB; chưa có artifact để tải.
- Chưa kiểm thử đăng nhập, tạo nhân vật, di chuyển, chiến đấu, đồng bộ nhiều người chơi trên OPPO.

## Các vấn đề kỹ thuật đã xác định
- Server source yêu cầu Go 1.26.0. Môi trường kiểm tra hiện tại có Go 1.23.2 và không truy cập được proxy để tải toolchain, nên chưa xác nhận compile/test tại đây.
- Client Cocos hiện là scaffold: script build trong package.json chỉ in hướng dẫn mở Cocos Creator 3.8.x; `ApiClient.baseURL` vẫn là placeholder.
- Server hiện là HTTP API + SQLite prototype, chưa có world server realtime/WebSocket hoặc trạng thái quái dùng chung giữa người chơi.
- Các công thức EXP, sát thương, cooldown và drop vẫn là thử nghiệm; cần test và cân bằng.
- Chưa có backup database chính từ gói source gốc; không sử dụng các tệp WAL/SHM sidecar như backup.

## Việc tiếp theo
1. Dùng Codex trong workspace có quyền ghi repository để nhập gói source sạch theo `docs/CODEX_HANDOFF_VI.md`.
2. Chạy GitHub Actions cho Go tests, vet, build và API smoke test; sửa lỗi đến khi PASS.
3. Hoàn thiện Cocos Creator project thực sự, scene, tài nguyên có giấy phép, input, UI và kết nối API.
4. Chỉ sau khi có staging ổn định mới kiểm thử trên VPS/OPPO; không đụng production cũ.
5. Build Android ARM64, cài lên thiết bị thật và kiểm thử end-to-end trước khi phát hành.

**Kết luận:** dự án đã có nền tảng tổ chức, kiểm toán source và pipeline CI; chưa có bản game Android hoàn chỉnh để tải về chơi.
